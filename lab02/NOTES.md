**Рабочая папка** — папка на компьютере, в которой находятся файлы проекта и выполняется работа с ними. Git отслеживает изменения в этой папке.

**Индекс** — промежуточная область Git, куда помещаются изменения, подготовленные для включения в следующий коммит. Можно выбрать только нужные изменения.

**Коммит** — зафиксированный набор изменений в проекте. Он сохраняется в истории Git и позволяет отслеживать изменения и возвращаться к предыдущим версиям.
