Рабочая папка — папка на компьютере, в которой находятся файлы проекта и выполняется работа с ними. Git отслеживает изменения в этой папке.

Индекс — промежуточная область Git, куда помещаются изменения, подготовленные для включения в следующий коммит. Можно выбрать только нужные изменения.

Коммит — зафиксированный набор изменений в проекте. Он сохраняется в истории Git и позволяет отслеживать изменения и возвращаться к предыдущим версиям.

**Git vs GitHub**

Git — программа для контроля версий. Она позволяет сохранять изменения в проекте, создавать коммиты, работать с ветками и возвращаться к предыдущим версиям.

GitHub — это онлайн-платформа, где можно хранить Git-репозитории в интернете, делиться ими и работать над проектами вместе с другими людьми.

**Использованные команды**

- git status — показывает состояние рабочего дерева и подготовленных изменений.
- git diff — показывает изменения в рабочей папке, которые ещё не добавлены в staging.
- git diff --staged — показывает изменения, подготовленные к коммиту.

** Ветки **

Ветка — это отдельная линия разработки в Git, которая позволяет работать над изменениями независимо от других веток.

При создании нового коммита ветка перемещается вперёд и начинает указывать на новый коммит.

Слияние (merge) объединяет изменения из одной ветки с другой.
