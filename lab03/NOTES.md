# Git notes

* `git diff` показывает различия между версиями файлов: что было добавлено, удалено или изменено.

* `git show` показывает содержимое конкретного коммита, включая изменения, которые этот коммит внёс.

* `git log` показывает историю коммитов.

* `git log -S"print" --oneline -- lab03/calc.py` ищет в истории коммиты, в которых изменилось количество вхождений строки `print` в `lab03/calc.py`.

* `git blame lab03/calc.py` показывает для каждой строки файла, каким коммитом и кем она была внесена или изменена.


# git restore

`git restore lab03/calc.py` восстанавливает файл из последнего коммита (`HEAD`). Незакоммиченные изменения в этом файле при этом удаляются.

`git restore --source=HEAD~2 lab03/calc.py` восстанавливает файл из указанного коммита, в данном случае из коммита `HEAD~2`. Поэтому рабочая версия файла становится такой, какой она была два коммита назад.

Если бы в `calc.py` были мои незакоммиченные правки, обычный `git restore` удалил бы их. Правки, которые не были сохранены в коммите, восстановить таким способом нельзя.
