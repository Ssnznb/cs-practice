# Lab 05 — Log Statistics

## Files
- `logstats.py` — functions for parsing log events and calculating statistics.
- `main.py` — reads a log filename, prints summary counts, and generates `report.txt`.
- `events.log` — main log file.
- `events-small.log` — small test log file.
- `report.txt` — generated statistics report.

## Run
From this directory, run:

    python3 main.py

Enter the log filename, for example `events.log`.
